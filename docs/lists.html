Option B: one import per country (fastest)

  1. On a computer, download the country's CSV file below.
  2. Go to mymaps.google.com → Create a new map → name it (e.g. "Thailand") → Import → choose the file.
  3. When asked, pick Latitude and Longitude for the pin position, then Name for the title.
  4. The map appears in the Google Maps app under You → Maps, with your rating and description on each pin.
